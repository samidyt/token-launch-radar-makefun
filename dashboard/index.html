The value model, in the open

Every row's implied value is one formula over the snapshot's own figures. No protocol name is special-cased; the same function scores every row.

implied = TVL × category multiple × growth × maturity × breadth

  category multiple   median market-cap / TVL of the snapshot's live-token
                      protocols in the same category, shrunk toward the
                      global median (weight n / (n + 5)) and clamped
                      to [0.03, 2.50]. No live comps → global median.
  growth              1 + clamp(change_7d, −60, +120) / 100 × 0.5
  maturity            0.6 + min(age_days, 1095) / 1095 × 0.4
                      (age unknown → 365 days)
  breadth             1 + 0.03 × min(chains − 1, 4)   (at most +12%)

What the radar does not do

  • It does not predict whether or when a protocol issues a token. A high implied value means the launch would be worth a lot if the protocol's record stayed as it is — nothing more.
  • It says a protocol records no token, never that it has none: a DefiLlama record can miss a token, and wrapped, staked or bridged products of tokens that already trade are left out of the board's claims. The Set aside tab lists the pre-token protocols the board does not rank, each with its reason.
  • Farm plans are generic steps derived from each protocol's category, chains, TVL and age. They are not financial advice; check the protocol's own pages before moving funds.
